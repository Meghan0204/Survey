# Survey Form

A responsive survey form built using **HTML** and **CSS** as part of my web development projects. This page collects feedback and user information through form inputs and demonstrates practical front‑end form design.

---

## Overview

This project contains a static **survey form** that includes various input types such as text fields, radio buttons, checkboxes, and dropdown menus. The form structure and styling help practice layout, responsiveness, and basic user interaction without backend logic.

---

## Features

✔ User input fields including text, email, and select menus  
✔ Multiple choice questions using radio buttons and checkboxes  
✔ Form layout styled with custom CSS  
✔ Simple, clean interface suitable for basic feedback collection

---

## Technologies Used

- **HTML5** – for structure and form elements  
- **CSS3** – for layout, styling, and basic responsive design  

---

## How It Works

- The form structure is defined in **`index.html`**, containing labeled fields for survey responses.
- **`styles.css`** contains the visual styling to make the form readable and easy to interact with.
- Input fields include text boxes, dropdowns, radio groups, and checkbox groups to collect a variety of responses.
